供应商 API 接入

网页登录使用的供应商密钥也可直接调用 API；密钥放在请求头，不要放进 URL。

01查询实际缺口

读取服务端账号快照中的 demands，选择 accepting=true 的策略，并以 needed 作为本次最多提交数量；updated_at 是快照时间。

02按数量提交 RT

将返回的 group_id 原样提交；refresh_tokens 支持用换行分隔多个 RT。

03根据结果继续

accepted 是成功数，failed 是拒绝数；提交后再次查询缺口，不要自行猜测数量。
